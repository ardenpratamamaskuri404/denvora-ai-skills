# Code of Conduct

## Our promise

This project is for people learning to build with AI, including complete beginners. We want everyone to feel welcome to ask questions, report problems, and contribute, whatever their experience, background, or language.

## Expected behavior

- Be kind and patient. Nobody was born knowing how to code.
- Assume good intent. Ask before concluding.
- Give feedback on the work, not the person.
- Respect both English and Indonesian speakers; use whichever you are comfortable with.

## Not acceptable

- Insults, mocking someone's skill level, or "just google it" dismissals
- Harassment, discrimination, or personal attacks
- Sharing other people's private information
- Spam or self-promotion unrelated to the project

## Enforcement

Maintainers may edit or remove comments, close issues, or block users who break these rules.

To report a problem privately, contact the maintainer through their GitHub profile: [@ardenpratamamaskuri404](https://github.com/ardenpratamamaskuri404).

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
